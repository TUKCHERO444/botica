# ¿Qué hace el sistema de botica y qué le aporta al negocio?

## En una frase

Es un sistema para **vender, controlar el inventario, cobrar, atender clientes y administrar la botica** desde un solo lugar, con una página web para que los clientes consulten productos y una parte interna para el personal del local.

No es solo una caja registradora: conecta la atención del cliente, el inventario, las compras, los vencimientos, la caja y los reportes.

---

## 1. Para el cliente que compra

### Página web de la botica

- Muestra los productos disponibles con foto, precio, categoría y marca.
- Permite buscar productos por nombre.
- Muestra el detalle de cada producto y si hay existencias.
- Permite consultar por WhatsApp directamente desde el producto.
- Muestra combos y promociones.
- Tiene una portada editable con banners, categorías destacadas y productos en oferta.

### Carrito de cotización

- El cliente puede agregar productos y combos.
- Puede cambiar cantidades.
- Puede descargar un PDF con el detalle.
- Puede enviar el carrito por WhatsApp para pedir una cotización.
- El carrito no cobra en línea: sirve para que el cliente consulte y luego concrete la compra en la botica.

### Cuenta de cliente

- El cliente puede registrarse y volver a ingresar.
- Puede ver y actualizar sus datos.
- Puede cambiar su contraseña.
- Puede consultar sus últimas compras y atenciones.

---

## 2. Para el personal de la botica

### Vender rápido y sin errores

- Buscar al cliente por nombre o DNI.
- Atender a un cliente nuevo sin llenar una ficha larga.
- Usar un cliente genérico para ventas rápidas.
- Agregar productos, servicios o ambos.
- Calcular el total automáticamente.
- Descontar del inventario al confirmar la venta.
- Registrar el ingreso en la caja del día.

### Vender por caja, blíster o unidad suelta

El sistema permite vender de distintas formas:

- una caja completa;
- un blíster;
- una tableta suelta;
- una cantidad en mililitros o gramos, si el producto se configura así.

Cada presentación puede tener su propio precio. Por ejemplo:

- Caja x 100 tabletas: S/ 50.00
- Blíster x 10: S/ 6.00
- Tableta suelta: S/ 0.80

El sistema descuenta del inventario la cantidad real que corresponde. No es necesario llevar dos inventarios separados.

### Controlar lotes y vencimientos

- Cada compra se registra con su lote y fecha de vencimiento.
- Cada lote recibe un número interno para poder ubicarlo.
- Al vender, el sistema descuenta primero el lote que vence antes.
- No permite vender productos vencidos.
- Muestra qué lotes están por vencer, críticos o ya vencidos.
- Permite dar de baja un lote vencido, dejando registro de esa salida.

Esto ayuda a reducir pérdidas por productos vencidos y a saber exactamente qué se vendió de cada lote.

### Registrar compras a proveedores

- Registrar la compra con proveedor, fecha, productos, cantidades, lote, vencimiento y costo.
- El sistema actualiza las existencias automáticamente.
- Guarda el historial de cada ingreso.
- No permite modificar una compra si parte de ese lote ya se vendió, para no perder el control.

### Atender servicios

Además de productos, se pueden registrar servicios como:

- toma de presión;
- control de glucosa;
- vacunación;
- inyecciones.

El total de la atención puede incluir productos y servicios, y todo queda registrado en la caja.

## 3. Para el dueño o administrador

### Saber qué está pasando

El tablero principal muestra, de forma rápida:

- ingresos del día;
- cantidad de ventas del día;
- cantidad de atenciones del día;
- productos con poco inventario;
- productos más vendidos del mes;
- productos que están por agotarse;
- lotes próximos a vencer y lotes vencidos con stock.

### Controlar el inventario

- Ver todos los productos, precios, existencias y estado.
- Saber qué productos están activos o inactivos.
- Definir un nivel mínimo de existencias para recibir una alerta visual.
- Ver el historial de entradas y salidas de cada producto.
- Consultar qué lote se usó en cada venta.
- Revisar lotes disponibles y vencimientos.

### Controlar la caja

- Abrir la caja con un monto inicial.
- Registrar gastos o egresos con su descripción.
- Ver los ingresos generados por ventas y atenciones.
- Cerrar la caja al final del turno.
- Consultar el historial de cajas cerradas.

### Administrar clientes

- Guardar datos de clientes.
- Buscar por DNI o nombre.
- Consultar automáticamente los nombres desde RENIEC al ingresar un DNI.
- Distinguir a los clientes que se registraron desde la web.
- Ver el historial de compras y atenciones de cada cliente.

### Administrar proveedores

- Guardar RUC, razón social y condición.
- Consultar automáticamente los datos desde SUNAT al ingresar un RUC.
- Asociar las compras a cada proveedor.

### Administrar usuarios y permisos

- Crear usuarios para el personal.
- Asignar roles: por ejemplo, administrador o vendedor.
- Definir a qué módulos puede entrar cada persona.
- Evitar que un usuario se desactive a sí mismo o se cambie su propio rol.

### Revisar la auditoría

- Saber quién creó, modificó o eliminó información.
- Ver qué cambió, cuándo y desde qué usuario.
- Filtrar por módulo, usuario, acción o fecha.

### Generar reportes

Se pueden generar reportes en PDF de:

- ventas;
- atenciones;
- compras/ingresos;
- caja;
- inventario;
- movimientos de inventario;
- clientes;
- resumen general del mes;
- auditoría.

Sirven para revisar el movimiento del negocio, sustentar decisiones y tener respaldo ordenado.

### Administrar la página web

- Elegir qué categorías aparecen en la portada.
- Subir banners del carrusel.
- Crear promociones y descuentos.
- Elegir productos para los espacios de “Más buscados”, “Más vendidos” y “En descuento”.
- Cambiar los textos informativos de la parte superior.
- Crear combos con precio especial.

## 4. Beneficios principales

### Menos pérdidas

- Control de vencimientos por lote.
- Salida primero de lo que vence antes.
- Bloqueo de venta de productos vencidos.
- Alertas visuales de lotes críticos.

### Mejor control del inventario

- Las existencias se actualizan con cada compra y venta.
- Se sabe qué producto, presentación y lote se movió.
- Se detectan productos con poco stock.
- Se evita vender sin existencia.

### Ventas más flexibles

- Se puede vender caja, blíster, unidad o fracción.
- Cada presentación tiene su precio.
- El cliente puede comprar exactamente lo que necesita.
- Aumenta la posibilidad de venta y mejora la atención.

### Menos trabajo manual

- Totales automáticos.
- Búsqueda de clientes y productos.
- Consulta de DNI y RUC.
- Reportes listos para descargar.
- Historial que no depende de cuadernos o hojas sueltas.

### Mejor atención al cliente

- Página web con productos y precios.
- Consulta por WhatsApp.
- Carrito con PDF.
- Historial de compras y atenciones.
- Registro y perfil del cliente.

### Más seguridad

- Usuarios con permisos.
- Auditoría de cambios.
- Historial de caja.
- Historial de inventario.
- Control de quién hizo cada operación.

### Información para decidir

- Productos más vendidos.
- Ingresos del día y del mes.
- Movimientos de caja.
- Productos con riesgo de agotarse.
- Reportes por período, cliente, proveedor o usuario.

## 5. Un día de uso, de forma simple

1. **Llega mercadería**  
   Se registra la compra al proveedor con producto, cantidad, lote y vencimiento. El inventario aumenta automáticamente.

2. **Un cliente pide 10 tabletas**  
   Se busca el producto, se elige “Tableta”, se coloca cantidad 10 y el sistema calcula el precio. Si hay varios lotes, descuenta primero el que vence antes.

3. **Se cobra**  
   La venta queda registrada, el inventario baja y el dinero ingresa a la caja del día.

4. **Se atiende un servicio**  
   Se registra la toma de presión o la inyección, junto con algún producto si corresponde. Todo suma al cierre de caja.

5. **Se revisa el inventario**  
   El administrador ve productos con poco stock y lotes próximos a vencer.

6. **Se cierra la caja**  
   El sistema calcula el monto final y guarda el historial.

7. **Se revisan reportes**  
   El dueño puede descargar ventas, compras, inventario o caja en PDF.

8. **El cliente entra a la web**  
   Consulta productos, arma su carrito, descarga la cotización o pide por WhatsApp.

---

## 6. Lo que el sistema no incluye

Para evitar expectativas equivocadas:

- **No cobra pagos en línea** ni procesa tarjetas desde la web.
- **No emite facturación electrónica** ni reemplaza a un sistema contable.
- **No gestiona delivery ni rutas de reparto.**
- **No maneja varias sucursales** en una misma instalación.
- **No es una historia clínica** ni gestiona recetas médicas.
- El carrito web es una **cotización**, no una compra pagada.
- El control de lotes y vencimientos ya está implementado, pero el inventario inicial debe cargarse correctamente por lote para obtener una trazabilidad real.

---

## 7. ¿Qué le aporta al negocio?

En resumen:

- **Orden:** todo queda registrado en un solo sistema.
- **Control:** inventario, caja, clientes y vencimientos.
- **Trazabilidad:** se sabe qué se vendió, de qué lote y a qué precio.
- **Menos pérdidas:** control de vencimientos y stock mínimo.
- **Ventas más flexibles:** caja, blíster, unidad o fracción.
- **Ahorro de tiempo:** menos cálculos y búsquedas manuales.
- **Mejor atención:** página web, WhatsApp, carrito y perfil del cliente.
- **Información para decidir:** reportes y tablero de control.
- **Seguridad:** usuarios con permisos y auditoría de cambios.

El sistema no solo registra ventas: **ordena la operación diaria de la botica y le da al dueño información confiable para tomar decisiones.**
